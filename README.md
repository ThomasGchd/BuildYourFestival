# BuildYourFestival

Roblox multiplayer festival tycoon built with Rojo.

## Vision
A large shared festival avenue leads to a permanent Mainstage playing music continuously. Eight players receive one personal plot each along the avenue and independently grow their own stage.

## Current systems
- Rojo multi-file project architecture
- Large shared avenue and Mainstage
- 8 unique player-owned plots
- 8 stage upgrade levels, cash and fans
- Spatial continuous Mainstage playlist
- Mainstage song queue prepared for a Robux Developer Product
- 20 Mainstage laser beams
- Optional music-reactive camera and HUD

## Setup
Install Rojo, clone this repository, run `rojo serve`, then connect with the Rojo Studio plugin.

Before publishing:
1. Set `Config.MainstageProductId` to the real Developer Product ID.
2. Verify/replace music asset IDs with audio permitted for the Roblox experience.
3. Test purchases in Roblox's supported test/publish workflow.
